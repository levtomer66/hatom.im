# hatom.im Shortcuts — setup guide

Drive hatom.im features from an iPhone/iPad/Mac **Shortcut** (home-screen tap,
Siri, or an Automation) using your **personal API key**. Building a shortcut in
the Shortcuts app yourself needs no signing and no "untrusted shortcuts"
setting — it's your own shortcut.

## 1. Get your key (once)

1. Sign in at **https://www.hatom.im**.
2. Tap your **avatar** (top of the navbar) → **API settings**.
3. **Generate** a key, then **Copy** it. It looks like `htm_xxxxxxxx…`.
4. (Coffee only) pick a **default coffee favorite** in the same dialog — the
   coffee shortcut orders that.

The key authenticates as you and can do anything you can on the site (order
coffee, page, edit to-dos…). Keep it private; **rotate** it in the same dialog
if it leaks — that instantly kills the old key.

> The old static paging token is gone. If you had a paging Shortcut, re-point it
> at your personal key using the steps below.

## 2. Coffee — "Order my usual" (simplest; one tap)

A body-less POST orders your **default favorite** (or built-in defaults).

New Shortcut → add these actions:

1. **Get Contents of URL**
   - URL: `https://www.hatom.im/api/coffee-order/orders`
   - (tap ▸ to expand) **Method:** `POST`
   - **Headers:** add one — key `Authorization`, value `Bearer htm_…` (paste your key)
   - **Request Body:** leave empty (no fields)
2. **Show Notification** → text: the *Contents of URL* variable (so you see the confirmation), or just "☕ Ordered".

Name it "Order coffee". Then **Share → Add to Home Screen** (one-tap button), or
say **"Hey Siri, Order coffee"**, or attach it to an Automation.

## 3. Paging — "Send a page"

Paging needs a short message, so the shortcut asks for one.

1. **Ask for Input**
   - Prompt: `Message`, Input Type: `Text`
2. **Text** (optional emoji) → e.g. `📟`
3. **Get Contents of URL**
   - URL: `https://www.hatom.im/api/paging/pages`
   - **Method:** `POST`
   - **Headers:** `Authorization` = `Bearer htm_…`; `Content-Type` = `application/json`
   - **Request Body:** `JSON`, two fields:
     - `emoji` (Text) = the emoji from step 2 (or a literal like `📟`)
     - `message` (Text) = the **Provided Input** variable from step 1
4. **Show Notification** → the *Contents of URL* result.

Name it "Page". Add to Home Screen / Siri / Automation as you like.

## 4. To-do — "Quick add task" (optional)

Needs the target **list id**. Get it once from the site (or ask the MCP tool
`list_todo_lists`); it's the id in the list URL `/todo/<listId>`.

1. **Ask for Input** → Prompt `Task`, Type `Text`
2. **Get Contents of URL**
   - URL: `https://www.hatom.im/api/todo/lists/<LIST_ID>/tasks`
   - **Method:** `POST`
   - **Headers:** `Authorization` = `Bearer htm_…`; `Content-Type` = `application/json`
   - **Request Body:** `JSON`:
     - `text` (Text) = the Provided Input
     - `column` (Number) = `0`
3. **Show Notification** → the result.

## The pattern (any feature)

Every feature API is `Authorization: Bearer <your key>` + the endpoint:

| Action | Method + URL | Body |
|--------|--------------|------|
| Order default coffee | `POST /api/coffee-order/orders` | *(none)* |
| Send a page | `POST /api/paging/pages` | `{ "emoji": "📟", "message": "…" }` |
| Add a to-do task | `POST /api/todo/lists/<listId>/tasks` | `{ "text": "…", "column": 0 }` |
| Book a spa session | `POST /api/spa/sessions` | `{ "scheduledAt": "ISO", "durationMinutes": 60, "preferences": "" }` |

A key only works for features your account is permitted to use; a wrong/rotated
key returns `401`, and a feature you're not allowed returns `403`.

## Sharing a ready-made shortcut (advanced)

To hand someone a pre-built shortcut instead of these steps: build it once, then
**Share → Copy iCloud Link** (Apple signs it), and send that link. Each person
still edits the `Authorization` header to paste **their own** key. (A shortcut
file generated by a server can't be imported — iOS requires Apple signing — so
authoring in the app or sharing an iCloud link are the only routes.)

## MCP (AI) — not a shortcut

For AI use, add `https://www.hatom.im/api/mcp` as a custom MCP connector with an
`Authorization: Bearer htm_…` header. Then ask your AI to "order my coffee",
"add milk to the shopping list", "page …", etc.
