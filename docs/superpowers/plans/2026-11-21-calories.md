# Calories Counter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A permission-gated `/calories` page where each person logs food against a daily calorie goal, reusing /shopping's catalog, nutrition, search and scanner.

**Architecture:** Pure, import-free logic in `src/lib/calories/` (tested with `node --test`); one model file `src/models/Calories.ts` (typed functions over five small collections); route handlers under `src/app/api/calories/`; a client page under `src/app/calories/` that wears shopping's CSS (`sh-page`) and reuses its `Scanner`, `Thumb`, `SwipeRow`, `useSwipeToClose`. MoH generic foods are loaded by a local CLI.

**Tech Stack:** Next.js 15 App Router, TypeScript, MongoDB driver (no ODM), React 19 client components, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-21-calories-design.md` (read it first; this plan does not repeat its screen descriptions).

## Review Focus

1. **A day across midnight / time zones**: the client sends its local `YYYY-MM-DD`; the server never derives "today". Test: `weekBars` with `endDate` `2027-01-02` returns `2026-12-27 … 2027-01-02`; a route given a malformed date answers 400.
2. **Product with no pack size, or sold by weight**: only the gram chip shows. Test in `unitsFor`.
3. **Duplicate taps on "הוספה"** (slow network): the client disables the button while the POST is in flight; the server rejects a 61st entry with 400. Test: `parseEntry` OK + model-level count check via `$expr`/`$size` filter (Task 4 step).
4. **Editing quantity rescales frozen totals proportionally** (not re-read from the catalog): `PATCH` with qty 2 on an entry logged at qty 1 doubles `nu`. Test `rescaleEntry`.
5. **Someone else's data**: every model call takes the caller's email; meals are filtered by `owner`. A `PATCH meals/[id]` for another owner's meal returns 404. Checked in the browser task by calling the route with a foreign id.
