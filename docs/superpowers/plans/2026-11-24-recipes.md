# Recipes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-person recipe book at `/recipes` with a shared feed, WhatsApp share, a 🛒 tick sheet to the household list, "רשום מנה" to /calories, and MCP tools for importing from social media.

**Architecture:** Own Mongo collection `recipes` (model `src/models/Recipe.ts`), import-free logic in `src/lib/recipes/*.ts` tested with `node --test`, route handlers under `src/app/api/recipes/*`, client pages under `src/app/recipes/*` wearing shopping + calories CSS. Calories gets one new ref kind (`recipe`); shopping is used only through `findProducts`, `householdFor`, `addLines`.

**Tech Stack:** Next.js 15 App Router, React client components, Mongo native driver, `@vercel/blob`, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-24-recipes-design.md` (read it with this plan).

## Global Constraints

- Hebrew RTL, phone-first (verify at 375 px); no save buttons — editors use `useAutosave` from `src/app/calories/autosave.ts`.
- `src/lib/recipes/*.ts` (except `mcp-tools.ts`, `server.ts`, `autolink.ts`, `match-server.ts`) are import-free for `node --test`: only relative `.ts` imports of other import-free modules (`../calories/calories.ts` qualifies), never `@/…`.
- Limits: name ≤ 120, servings 1–100, ingredients ≤ 60 (text ≤ 200), steps ≤ 40 (each ≤ 1000), tags ≤ 10 (each ≤ 30), prep/cook 0–1440, notes ≤ 2000.
- Photos only in Vercel Blob (`recipes/<id>-<rand>.jpg`), never bytes in Mongo.
- Never touch `caloriesMeals`. Never write My items from recipes (the list only).
- Node: `/opt/homebrew/bin/node`; tests `npm test` (runs `node --test "src/**/*.test.ts"`); build needs `MONGODB_URI=mongodb://127.0.0.1:27018/hatom-shopping-test`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. The pre-commit hook runs tests + build; keep it on for code commits.
- Dev server: `.claude/launch.json` entry `recipes-local` → `/opt/homebrew/bin/node scripts/dev-local.mjs -p 3260`, started with the preview tools.

## Review Focus

1. A pasted line with no amount ("מלח", "חופן פטרוזיליה") — must parse to `qty: null`, render unchanged at any servings, and not mark nutrition partial.
2. Mixed number + fraction and unicode fractions ("1 1/2 כוסות", "1½ כוס") — must parse to 1.5, not 1 or 11.
3. A recipe whose lines are all unlinked — kcal shows nothing (not 0), "רשום מנה" is disabled, calories search does not list it.
4. A feed recipe unshared/deleted by its owner while another user has it open or calls `copy` — 404, no copy made.
5. Two quick edits (type in an ingredient, then a step) — both persist in order; a PATCH must merge only the fields sent, never overwrite the other field with stale data.

Each has a test in the owning task (Tasks 1, 1, 2, 4, 3).
